# 📚 Book Recommendation System Using Knowledge Graphs and Cypher

A book recommendation system that uses a **Knowledge Graph** to recommend books based on relationships between books, authors, genres, and topics.

The system is built using **Neo4j AuraDB, Cypher, Python, and Streamlit**. Instead of using a traditional machine learning model, recommendations are generated by finding related books in the knowledge graph and calculating a similarity score based on shared information.

## 🚀 Live Demo

[Open the Book Recommendation System](https://pfrhzc8chjckxnakpyehon.streamlit.app/)

## 🎯 Project Objective

The main objective of this project is to demonstrate how **Knowledge Graphs can be used for recommendation systems**.

When a user selects a book, the system finds other books that share:

* The same author
* The same genre
* Similar topics

The shared relationships are converted into a recommendation score, and the top 5 related books are displayed.

## 🧠 Knowledge Graph

The project uses Neo4j to represent book information as a graph.

The main entities are:

* **Book**
* **Author**
* **Genre**
* **Topic**

The relationships are:

```text
Book ──WRITTEN_BY──> Author
Book ──HAS_GENRE───> Genre
Book ──HAS_TOPIC───> Topic
```

This structure allows the system to discover connections between books through their shared graph relationships.

## ⭐ Recommendation Logic

Each candidate book receives a score based on its relationship with the selected book:

| Shared Information | Score |
| ------------------ | ----: |
| Same author        |    +3 |
| Each shared genre  |    +2 |
| Each shared topic  |    +1 |

Books with a score greater than zero are considered recommendations.

The system then sorts the results by score and displays the **top 5 recommendations**.

For example, if two books have the same author, genre, and topic:

```text
Same author     → 3 points
Same genre      → 2 points
Same topic      → 1 point

Total           → 6 points
```

The recommendation reason is also generated dynamically from the shared graph information.

Each book is connected to its author, genres, and topics in the Neo4j knowledge graph.

## ⚙️ How It Works

1. The user selects a book from the Streamlit interface.
2. Python sends the selected book title to Neo4j.
3. A Cypher query finds other books connected through common authors, genres, and topics.
4. A recommendation score is calculated for each related book.
5. The results are sorted by score.
6. The top 5 recommendations are displayed.
7. The system also explains why each book was recommended.

## 🔐 Configuration

Neo4j credentials are stored using environment variables rather than being included directly in the source code.

For local execution, create a `.env` file containing:

```env
NEO4J_URI=your_neo4j_uri
NEO4J_USERNAME=your_neo4j_username
NEO4J_PASSWORD=your_neo4j_password
NEO4J_DATABASE=your_neo4j_database
```

The `.env` file should **not** be committed to GitHub.

For deployment, the same variables are configured using Streamlit Secrets.

## ▶️ Run Locally

Make sure Python and the required packages are installed.

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the Streamlit application:

```bash
streamlit run app.py
```

The application will open in the browser.

## 🌐 Deployment

The application is deployed using **Streamlit Community Cloud** and connected to **Neo4j AuraDB**.
